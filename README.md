# Graphene Field-Effect Transistor (GFET) Nanobiosensors

## Overview
This repository contains the research, literature review, and reports pertaining to Graphene Field-Effect Transistor (GFET) based Nanobiosensors. The project focuses on exploring the fabrication, optimization, and real-world applications of graphene-based sensors for highly sensitive biological and chemical detection.

## Contents
- **Literature & Patents**: Comprehensive collection of research papers and patent documents (US & EP) outlining the current state-of-the-art in nanobiosensors and graphene technologies.
- **Technical Reports**:
  - `SOP_Nanobiosensor_Report.pdf` / `.docx`: Detailed study-oriented project report summarizing the workings, advantages, and future scope of GFET sensors.
  - `SOP-Nanobiosensors.pptx`: Presentation slides summarizing the findings.
- **Data & Visualizations**:
  - Experimental and expected graphical analyses comparing different gating and doping techniques (`Expected Graph`, `Actual Graph`).
  - Directory on specific `DopingTechniques` utilized to modulate the Dirac point and sensitivity of GFETs.

## Applications
GFETs leverage the exceptionally high carrier mobility and 2D nature of graphene to achieve label-free, real-time detection of biomolecules, DNA, and viruses at ultra-low concentrations, making them a cornerstone for next-generation point-of-care diagnostics.
